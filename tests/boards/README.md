# テスト用の機種の行

`tests/test_i2c.py` だけが読む、実在しない機種の行です。形式は `config/devices/` と同じです。

`fd8f1` は PIX-DT295 の行と同じ形（selene の配置、`0x00FD8FE0` の I2C、地上と衛星の復調 IC）ですが、
チューナーも機種固有の設定も持ちません。I2C と復調の経路だけを、実在の機種の行から切り離して確かめるために置いています。
`fd8f2` は、復調 IC を 2 組持つ形です。`config/` にはこの形の機種がありません。

| id | 形 |
|---|---|
| `fd8f1` | `fujitsu-fd8f`、復調 IC 1 組（地上 `0x10`、衛星 `0x11`） |
| `fd8f2` | 同じ構成で 2 組（2 組目は `0x12`・`0x13`） |

USB ID の `FFFF:xxxx` は仮の値です。`loader` が無いのでコンテナはビルドされず、`host/build.py` もこの場所を見ません。
