# `config/`（ビルドの設定）

機種ごとの違いは、C のコードではなくここの設定に書いてあります。I2C の経路・復調 IC・チューナーの組み合わせは
ここで決まります。イメージは機種ごとに 1 本で、ビルドのときに
[`../host/genboards.py`](../host/genboards.py) がその機種の行を
`build/board_<id>.c`（`fw_board` 1 件）に変換し、そのイメージにだけリンクします。
ファームウェアは、動いている機器を調べません。
各列の意味と機種を追加する手順は [`../docs/devices.md`](../docs/devices.md) にあります。

| | |
|---|---|
| [`fw.json`](fw.json) | 主 FR の配置・ソース・ターゲットです。`build.py` が読みます |
| [`armcore.json`](armcore.json) | ARM のコアに載せるイメージ（`armcore.bin`）のビルドの設定です。`build.py` が読みます。ツールチェイン `arm-none-eabi` が無ければ、このイメージだけを飛ばします |
| [`auxcore.json`](auxcore.json) | 補助コアのイメージのビルドの設定です。`aux.json` という名前にしていないのは、Windows では `AUX` が拡張子つきでも予約名だからです |
| [`drivers.json`](drivers.json) | ドライバの表です。機種をまたいで共有します。各ドライバの裏取りの段階（`evidence`）も持ちます |
| [`devices/`](devices) | 機種 1 つにつき 1 ファイルです。ドライバの組み合わせ・I2C アドレス・裏取りの段階・常駐ローダ（`loader`）を書きます。ここにあるのは、その行でビルドしたイメージが実機で動いた機種だけです |
| `untested/` | 同じ形式で、その行のイメージがまだ実機で 1 度も動いていない機種を置く場所です。今は 1 件も無いので、ディレクトリもありません。`loader` があればコンテナはビルドされます。実機で動いたら `devices/` へ移します |

## `loader`（常駐ローダの情報）

その機種の常駐ローダのどこに何があるかを書きます。どれも実機のチップから読んだ値です。

`loader` が `null` でない機種が、FRC1 コンテナのターゲットになります。
`loader` を持つのは、ローダを実機で測った機種だけです。

| | |
|---|---|
| `name` | コンテナに埋め込むターゲットの名前です。文字列の表に入るので、変えると `frc1-<id>.frc` のバイトが変わります。製品名（`name`）とは別のものです |
| `family` | ローダの世代です。`selene` か `dione` のどちらかです。`build.py` はこれで入口の stub（`src/main/entry_frc1_selene.S`・`src/main/entry_frc1_dione.S`）とリンクスクリプト（`src/main/link_selene.ld`・`src/main/link_dione.ld`）を選びます |
| `hook` / `hook_crc32` | 差し替える番地と、元の 8 バイトの指紋（`zlib.crc32`）です。ローダのバイト列はこのリポジトリに置いていません。照合は指紋で足り、`restore` 用の控えは `install` がチップから読んで `<file>.frc.hook` に保存します。控えが無くても、抜き差しすれば元に戻ります（ローダは RAM にあります） |
| `boot` | その機種で `.boot` を置ける空き領域です。hook の stub の飛び先で、`ldi:20` の即値に収まる `0x100000` 未満の番地である必要があります。番地の元は `family` のリンクスクリプト（[`../src/main/link_selene.ld`](../src/main/link_selene.ld)・[`../src/main/link_dione.ld`](../src/main/link_dione.ld)）の `BOOT_BASE` で、食い違うとビルドのときにエラーになります。リンクスクリプトは世代ごとに 1 本なので、違う番地が必要な機種ではリンクスクリプトを分けることになります |
| `resume_plain` / `resume_mask` / `complete` / `staging` / `state` | 入口の stub が使う番地です。`family` の入口（`src/main/entry_frc1_selene.S`・`src/main/entry_frc1_dione.S`）が `.equ` で持っている番地は、食い違うとビルドのときにエラーになります |
| `base` / `bytes` | ローダ自身の置き場所と長さです |
| `crc32` | ローダの指紋（先頭 `bytes` バイトの `zlib.crc32`）です。インストールのときに「このローダ向けにビルドしたものか」を確かめ、違えばインストーラが拒否します。値の求め方は [`../host/README.md`](../host/README.md) にあります。`null` なら検査しません |

値が同じでも、機種ごとに持っています。同じ世代の機種どうしで番地・長さ・hook の指紋が一致しても、
それは測った値が一致したもので、世代として決まった値ではありません。

USB ID は `loader` に書きません。行の `usb` から取ります。

コンテナは機種ごとに 1 本（`build/frc1-<id>.frc`）です。1 本に 1 ターゲット
で、中のイメージもその機種の行でリンクしてあります。`loader` を持つ機種を増やしても、
コンテナの本数が増えるだけで、既にあるコンテナのバイトは変わりません。

## `bands`（受信帯、IDENTIFY の頁 1）

機種の行には、受信帯を 2 つまで書けます。無ければ帯は 0 個です。ファームウェアは
`IDENTIFY` の `arg0 = 1` でそれをそのまま返します（[`docs/frq1.md`](../docs/frq1.md)）。

| 鍵 | 中身 |
|---|---|
| `source` | `t`・`t2`・`s`・`s2` |
| `tuned_by` | `host` だけです（ホストが `I2CXFER` で選局します。ファームウェアに選局のコマンドはありません） |
| `lock_seen` | 帯の中でロックを実測したかどうか |
| `record` | レコード長（TS なら 188） |
| `lo_khz`・`hi_khz` | 中心周波数の下限・上限 |
| `step_hz` | チューナーの刻み |

`genboards.py` が鍵と範囲を検査します。

## `devices/` と `untested/` の違い

`genboards.py` は 2 つのディレクトリをまとめて読み込みます。形式は同じで、
違うのは、その行でビルドしたイメージが実機で動いたかどうかだけです。

| | |
|---|---|
| `devices/<id>.json` | この行のイメージが実機で動いたことがある |
| `untested/<id>.json` | 1 度も動いていない |

`frc1-<id>.frc` をその機種に書き込んで、このイメージが
答えたら `devices/` へ移します。IDENTIFY の `+0x08`
（[`../docs/frq1.md`](../docs/frq1.md)）がその行の USB ID を返すので、
どの行のイメージが答えたかはホストから直接確かめられます。
動いたかどうかは置き場所だけで表し、表の中に「動いた」を書く鍵はありません。

今は `untested/` に 1 件もありません。`devices/` には GV-M2TV（`m2tv`）・PIX-DT295
（`dt295`）と、製品を指定しない `unknown` の 3 件があります。

`build.py --list` は `2/2` と表示します（`dt295`・`m2tv`）。`unknown` は製品ではないので
数に入りません。この一覧の表はビルドの設定を示すもので、動作を確かめたかどうかを示すものではありません。

## `unknown`（製品を指定しない行）

`usb` が `null` の行はちょうど 1 つ（`unknown`）です。どの機種でもないイメージ、
ほとんどのテストで走らせるイメージは、この行でリンクします。RF 側もカードもすべて
`FW_ENOTIMPL` を返し、FRQ1 の枠には答えます。

ファームウェアは動作中に USB ID で表を引きません。1 コンテナが 1 機種に対応しているためです。

## 表の検査

`genboards.py` は、ファイル名と `id` の不一致・`usb` が `null` の行が
1 件でないこと・USB ID の重複・鍵の欠け・ドライバが
無いのに `evidence` が `unknown` でない行を拒否します。並びはファイル名の順で、
動作には影響しません。
